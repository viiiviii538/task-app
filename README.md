# やさしいタスク共有アプリ

## このアプリでできること
- スマホ/PCに不慣れな人でも使いやすい、**1画面で完結**するタスク管理。
- 利用者は2人固定（「あなた」「パートナー」）。
- タスク項目（タブ）を自由に追加可能（例：社会、プライベート）。
- タスクは**タブ単位ではなく、タスク単位で共有**を設定可能。
  - `共有`: 2人が見られる
  - `自分だけ`: 作成者だけ見られる
- 共有タスクの完了/未完了状態を2人で確認可能。

## ファイル構成
- `index.html`: 画面の骨組み
- `style.css`: 見た目
- `app.js`: 画面操作と保存処理
- `taskCore.js`: タスク管理ロジック
- `tests/unit.test.js`: 単体テスト
- `tests/integration.test.js`: 結合テスト

## 起動方法（初心者向け）
1. このフォルダで以下を実行：
   ```bash
   python3 -m http.server 8000
   ```
2. ブラウザで `http://localhost:8000` を開く。
3. 画面上部の「操作中の利用者」を選び、タブやタスクを追加する。

## スマホでもPCでも同じように使うためのポイント
- このアプリはレスポンシブ対応済みです。画面幅が変わっても、**機能の並び順と意味は同じ**です。
- スマホではタップしやすいようにボタン高さを広めにしています。
- 文字サイズはスマホで拡大されにくいように調整しています（入力欄16px以上）。

## スマホ実機デバッグ手順（省略なし）
以下は「PCでサーバーを動かし、スマホでアクセスする」一番わかりやすい方法です。

### 0) 事前準備
- PCとスマホを同じWi-Fiにつなぎます。
- PC側でこのプロジェクトフォルダを開きます。

### 1) PCでローカルサーバー起動
```bash
python3 -m http.server 8000
```
> 注意: このコマンドは待機し続けます（正常動作）。停止は `Ctrl + C` です。

### 2) PCのIPアドレスを調べる
mac/Linux:
```bash
hostname -I
```
Windows (PowerShell):
```powershell
ipconfig
```
- 例として `192.168.1.23` が出たら、スマホ側URLは  
  `http://192.168.1.23:8000` です。

### 3) スマホでアクセス
- スマホのブラウザ（Chrome/Safari）で上記URLを開きます。
- タブ追加、共有/非共有、完了チェックを操作して表示崩れがないか確認します。

### 4) スマホ表示を重点確認（チェックリスト）
- ボタンが押しやすい（小さすぎない）
- 文字が潰れていない
- 横スクロールが出ない
- 「共有タスク」が別ユーザーでも見える
- 「自分だけタスク」は別ユーザーから見えない

### 5) スマホでの不具合をPCで詳しく調べる（任意）
#### Android + Chrome
1. スマホの開発者向けオプションでUSBデバッグをON  
2. USB接続  
3. PC Chromeで `chrome://inspect` を開く  
4. 対象タブをInspectしてConsoleエラー確認

#### iPhone + Safari
1. iPhone: 設定 > Safari > 詳細 > WebインスペクタをON  
2. Mac Safari: 設定 > 詳細 > メニューバーに\"開発\"を表示  
3. USB接続し、Safariの開発メニューからiPhoneのページを選択

### 6) ありがちな詰まりポイント
- スマホから開けない → PC/スマホが別Wi-Fiの可能性
- URLが違う → `localhost` ではなく **PCのIP** を使う
- 変更が反映されない → スマホで再読み込み（必要ならキャッシュ削除）

## 高校生向けのかんたん解説
- **タブ**は「科目ごとのノートの仕切り」のようなものです。
- **共有タスク**は「2人で見る掲示板のメモ」、**自分だけ**は「自分のメモ帳」です。
- チェックボックスを入れると「完了」扱いになります。
